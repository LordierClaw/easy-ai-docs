# Git portable

Contract kỹ thuật, mặc định ensure. Script kiểm Git hệ thống đạt version yêu cầu → cache hợp lệ → tải ZIP từ release easy-ai-docs. Resource artifact.json ghim URL, version, size và SHA256 theo revision contract. Kiểm ZIP, đường dẫn, hash file và executable trước sử dụng. MinGit không có Git Bash.

Thành công ghi pathPrepend vào EASYAI_ENV_PATH; runner truyền cho script sau và contract cha. Không sửa PATH hệ thống. doctor chỉ báo hiện trạng, không tải, cài hoặc xuất PATH. Cache đã kiểm chứng dùng được khi offline. Cache hỏng không được thực thi; script báo lỗi và cho chọn hỗ trợ mạng/cài đặt.
