# Claude Code

install/repair kiểm Git, chạy installer Anthropic đã ghim checksum nếu CLI chưa có, tạo shortcut **Claude Code (EasyAI)**, chờ đăng nhập rồi kiểm trạng thái bằng CLI. configure chỉ tạo launcher cho CLI đã có; auth kiểm đăng nhập. doctor báo hiện trạng và không sửa máy.

CLI nằm ở thư mục .local/bin của tài khoản Windows. Mở shortcut, làm theo đăng nhập chính thức rồi quay lại EasyAI để tiếp tục. Không cung cấp credential trong chat. Git portable của EasyAI là MinGit, không chứa Git Bash; nếu phiên bản Claude cần Bash, chuẩn bị Git for Windows đầy đủ theo hướng dẫn của nhà cung cấp/IT.

Checksum bootstrap không khớp sẽ dừng; người duy trì cần xem xét và publish bản contract mới. Không bỏ qua checksum để chạy installer đã thay đổi. Bản này mới kiểm metadata và PowerShell; chưa nghiệm thu cài Claude thực tế.
